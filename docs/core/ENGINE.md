# Native engine slice (core5)

This slice is prerequisite work, **not a first-map gameplay pass**. The real flow reaches state 10/step 0 at VBlank 2204 and stops in `Gfx_LoadScreenMapEffectsUpdate/native environment`. The original loading-player callback and full startup dispatcher are linked; environment/character/world drawing, NPC initialization and gameplay/player updates remain guarded. No pad-driven walking or automatic camera-follow result is established.

`prepare_camera.py` imports the four original camera translation units and explicit native work records. `prepare_math.py` translates the pinned GPL rotation kernels at build time and imports the reference SDK's atan/sqrt/inverse-sqrt constants. No owned game is read during generation and no runtime MIPS interpreter is linked. Unit checks exercise octants, SDK quantization, three rotation axes, preserved translations, and original bone interpolation over immutable synthetic bytes. The parser must keep operand-free instructions on their own line; a test caught and corrected a skipped multiply after a nop.

`prepare_world.py` preserves original four-slot scheduling, material references, texture-page selection and readiness checks. The slots hold native descriptors; AssetStore owns their separate leaves and shared global LM graphs. Queue publication clears logical IPD/global-PLM readiness until original material initialization runs; decoded native pointers alone do not certify texture readiness. Center-relative PS1 grid indexing is checked against the native 19x16 grid. Original texture references reset on replacement/reset, but graph caches remain alive for the worker lifetime; memory-budget/eviction behavior across all maps is pending.

`prepare_collision.py` links the original 29-function ground-query dependency closure. Its native work records carry exact size/offset assertions. Existing decoded numeric IPD leaves stay separate from immutable serialized storage. Ground-only cylinder classification is initialized because that query does not classify a character; the reference's otherwise uninitialized byte is not propagated into native C.

The missing reference water filename is eight bounded scalar bytes, read and decrypted at runtime using BODYPROG's pinned symbol offset. Its NUL-terminated prefix is validated; following alignment bytes are not part of the name. No copied game string, executable code or extracted asset is in Git.

Run `target/release/silent-hill-boot.exe --probe-world --audio off` after a release build with an owned disc. It uses the original scheduler to sample the spawn, 40m down the road and back, drains queues, checks non-fallback surfaces, verifies the original loading user-camera targets and Q8 view quantization, and resets the slots. This is a streaming/camera service diagnostic: it does not move Harry, execute gameplay input, draw the world, or transition overlays. Replay/screenshot/milestone flags are rejected for this mode.

`tools/check-native-clang.py` now checks all 18 native C units for arm64. It uses compile-only CRT declarations with the installed LLVM frontend; it cannot certify an Apple SDK build or runtime. The local Apple target Rust check is blocked by psxgpu's need for xcrun. MSVC /WX and Apple's existing warning-reporting policy remain unchanged.
