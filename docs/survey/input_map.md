## Bindings and pipeline

`Settings_RestoreControlDefaults` supplies the USA bindings: [src/bodyprog/sys/settings_reset.c:35](https://github.com/Vatuu/silent-hill-decomp/blob/d9e28f8315c7938117224f21516786d9d149a145/src/bodyprog/sys/settings_reset.c#L35). Preset 1 swaps aim/search/step shoulder assignments; preset 2 swaps map/inventory. The native UI should dispatch semantic actions through the active configuration, with separate literal-button paths for debug-only consumers.

P1 samples come from the buffer registered by `PadInitDirect`, copied by `Joy_ReadP1`; `MainLoop` calls it before demo replacement and input conversion. Blocking logo/movie loops call `Joy_Update` separately. Held flags invert active-low pad bits; analog sticks generate low/high threshold directions, D-pad generates high-threshold directions and normalized axis values. Click/release edges are distinct from repeating pulses (nominal 30-vblank initial delay, three-vblank repeats). Evidence: [src/bodyprog/sys/joy.c:10](https://github.com/Vatuu/silent-hill-decomp/blob/d9e28f8315c7938117224f21516786d9d149a145/src/bodyprog/sys/joy.c#L10), [src/bodyprog/sys/joy.c:16](https://github.com/Vatuu/silent-hill-decomp/blob/d9e28f8315c7938117224f21516786d9d149a145/src/bodyprog/sys/joy.c#L16), [src/bodyprog/sys/joy.c:39](https://github.com/Vatuu/silent-hill-decomp/blob/d9e28f8315c7938117224f21516786d9d149a145/src/bodyprog/sys/joy.c#L39), [src/bodyprog/sys/joy.c:71](https://github.com/Vatuu/silent-hill-decomp/blob/d9e28f8315c7938117224f21516786d9d149a145/src/bodyprog/sys/joy.c#L71), [src/bodyprog/sys/joy.c:95](https://github.com/Vatuu/silent-hill-decomp/blob/d9e28f8315c7938117224f21516786d9d149a145/src/bodyprog/sys/joy.c#L95), [src/bodyprog/sys/game_main.c:164](https://github.com/Vatuu/silent-hill-decomp/blob/d9e28f8315c7938117224f21516786d9d149a145/src/bodyprog/sys/game_main.c#L164).
